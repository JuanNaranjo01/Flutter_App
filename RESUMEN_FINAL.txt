🔒 MANEJO DE ERRORES (8 TIPOS)

✅ Sin conexión WiFi
   └─ Mensaje: "No se pudo conectar al servidor. Verifica tu conexión WiFi."
   └─ Acción: Reintentar automático (2x)

✅ Timeout en búsqueda (>15s)
   └─ Mensaje: "El servidor tardó demasiado en responder. Intenta de nuevo."
   └─ Acción: Reintentar automático (2x)

✅ Timeout en procesamiento (>60s)
   └─ Mensaje: "El servidor tardó procesando las imágenes"
   └─ Acción: Reintentar automático (2x)

✅ Estudiante no encontrado (404)
   └─ Mensaje: "Estudiante con código XXX no encontrado en BIENESTAR"
   └─ Acción: Volver a búsqueda

✅ Estudiante ya tiene embeddings (409)
   └─ Mensaje: "El estudiante ya tiene X embeddings. Use force_update=true"
   └─ Acción: Opción de actualizar o cancelar

✅ Imagen mayor a 2MB
   └─ Mensaje: "❌ La imagen no debe exceder 2MB"
   └─ Acción: Opción de recapturar

✅ Menos de 3 fotos
   └─ Mensaje: "❌ Debes capturar al menos 3 fotos"
   └─ Acción: Instrucción informativa

✅ Imagen sin rostro detectado
   └─ Mensaje: "No se detectó rostro en foto X"
   └─ Acción: Mostrar en lista de fallos

🚀 PRÓXIMOS PASOS PARA USAR

1️⃣ CONFIGURAR SERVIDOR
   ├─ Asegúrate que corre en http://192.168.100.99:5000
   ├─ Implementa endpoints:
   │  ├─ POST /api/search_student
   │  └─ POST /api/register_student_embeddings
   └─ Verifica permisos CORS

2️⃣ CONFIGURAR APP (OPCIONAL)
   └─ Si URL es diferente, edita:
      └─ lib/config/api_config.dart, línea 2

3️⃣ INSTALAR DEPENDENCIAS
   └─ flutter pub get (ya ejecutado ✅)

4️⃣ EJECUTAR APP
   └─ flutter run

5️⃣ PROBAR FLUJO
   ├─ Abre app → Tab "Registrar"
   ├─ Ingresa código de estudiante
   ├─ Captura 4 fotos
   ├─ Revisa resultado
   └─ ¡Listo! ✅
